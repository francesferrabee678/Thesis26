# Semantic segmentation replication

For visual grounding replication the following steps have to be followed

1. run Thesis26/lexicon3d/jobs/main[model_name].sh
2. for the visualizations run either the test script or the score script(which is a modified version of the test script with per scene confidence scores) following the logic used here lexicon3d/jobs/test_grounding.sh

then run the visualization script: Thesis26/lexicon3d/jobs/segmentation_visual_results.sh, you can change the scene name as well as the model used.
